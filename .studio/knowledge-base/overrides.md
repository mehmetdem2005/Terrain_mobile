# Honesty Auditor Override Record

Permanent record of every time the Honesty Auditor's veto was overridden. Each override required Tech Director or Studio Head signature and an auto-postmortem ticket.

This file is append-only. Overrides are expensive on purpose; they should be rare.

## Format

```
## OVR-NNN — TKT-NNN — YYYY-MM-DD
- Overriding role: <Studio Head | Tech Director>
- Overridden blocker: BLK-NNN-MM
- Original veto reason: [what Honesty Auditor flagged]
- Override rationale: [why the override was granted]
- User sign-off: [link to user message accepting risk, if applicable]
- Auto-postmortem ticket: TKT-NNN
- Postmortem outcome: [if available]
```
