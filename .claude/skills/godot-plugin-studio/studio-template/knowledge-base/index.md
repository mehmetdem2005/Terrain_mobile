# Studio Knowledge Index

The active spine of the studio's Knowledge Loop (per `references/knowledge-loop-protocol.md`).

Every lesson harvested at ticket close is registered here. Every new ticket at Phase 1.B consults this index. The Studio Knowledge Curator owns this file.

When this file is empty, the studio remembers nothing. Keep it populated.

---

## How to use this index

**Reading (pre-ticket consult — Phase 1.B):**
1. Identify the ticket's categories and tags from the request
2. Scan the relevant category section below
3. Scan the relevant tag section below
4. Follow links to lessons.md files for full context
5. Produce `relevant-lessons.md` in the new ticket's audit trail

**Writing (lesson harvest — Phase 1.G close):**
1. Verify `lessons.md` exists in the closing ticket
2. For each lesson, append a line under the matching category
3. For each tag in the lesson, append a line under the matching tag section
4. If a category or tag doesn't exist yet, create it

Entry format: `- L-<NNN> (<TKT-NNN>, <confidence>): <one-line title> → <link to lessons.md#L-anchor>`
