# Architecture Decision Records

ADRs documenting architecturally significant decisions. Each is recorded by the Architecture Decision Recorder after an Architecture Review Board decision.

## Numbering

ADRs are numbered sequentially: ADR-001, ADR-002, etc. Numbers are not reused even when an ADR is superseded.

## Format

See `references/02-tech-leadership.md` for the ADR template. Each ADR is a single markdown file: `ADR-NNN.md`.

## Status field

- **PROPOSED** — under discussion
- **ACCEPTED** — current decision
- **SUPERSEDED-BY-ADR-NNN** — replaced by a later decision; keep the file for history
- **DEPRECATED** — no longer relevant, but kept for context

## Reading order

ADRs are not strictly time-ordered; later ADRs may supersede earlier ones. To find the *current* answer to a question, look for ACCEPTED ADRs by topic, not by date.
