# Recurring Defect Patterns

Defects that have appeared in 2+ tickets. Patterns here trigger preemptive checks in future tickets — the studio learns to look for them.

## Format

```
## <Pattern name>
- First encountered: YYYY-MM-DD (TKT-NNN)
- Repeated in: TKT-NNN, TKT-MMM, ...
- Description: [the defect class]
- Catching role(s): [which roles should be watching for this]
- Preemptive check: [what to do at triage to prevent recurrence]
```
